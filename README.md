Enterprise HRMS + HR Services Platform

An enterprise-ready, multi-tenant Human Resource Management System (HRMS) designed for Indian small and medium-sized businesses, with a roadmap toward enterprise-scale HR operations.

Project Overview

This project aims to build an integrated HR platform that simplifies employee management, leave and attendance tracking, recruitment, and employee self-service through a centralized SaaS application.

The long-term vision is to expand into payroll, HR services, analytics, and AI-powered HR automation.

MVP Scope

The initial Minimum Viable Product (MVP) will focus on:

* Core HRMS: Company setup, employee profiles, departments, designations, and employee lifecycle management.
* Leave & Attendance: Leave requests, approvals, attendance tracking, and attendance records.
* Recruitment / ATS: Job openings, candidate management, and recruitment pipeline tracking.
* Employee Self-Service: Employee profiles, leave requests, attendance history, and authorized HR information.

Planned Technology Stack

* Frontend: Next.js, React, TypeScript
* UI: Tailwind CSS, shadcn/ui
* Backend: NestJS, TypeScript
* Database: PostgreSQL
* Authentication: Managed identity provider — selection pending
* Cloud: AWS
* Development: Local environment first, followed by AWS deployment
* Version Control: Git and GitHub

Technology selections and implementation details will be finalized during the architecture phase.

Architecture Principles

* Multi-tenant SaaS architecture
* Strong tenant isolation and role-based access control
* Modular backend architecture
* API-first design
* Secure handling of employee information
* Auditable HR operations
* Scalability without unnecessary initial complexity
